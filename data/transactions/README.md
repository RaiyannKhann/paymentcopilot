# Mock transactions

`transactions.csv` is **entirely synthetic**, generated by [`scripts/generate_transactions.py`](../../scripts/generate_transactions.py) with a fixed random seed. It contains no real merchants, transactions, or PII of any kind — merchant IDs (`demo-merchant`, `acme-retail`, `globex-travel`) are fictitious placeholders created for this project.

Regenerate with `python scripts/generate_transactions.py`, then reload Postgres with `python scripts/seed_transactions.py`.
